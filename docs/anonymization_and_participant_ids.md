# Anonymization and participant identifiers

Public participant identifiers were reassigned sequentially as `sub-01` to `sub-27`.

Original laboratory participant numbers and original ERPLAB filenames are not included in the public repository. The original-to-anonymized correspondence is stored only in a private local file and is not part of the public dataset.

The public files therefore use continuous anonymized identifiers from `sub-01` to `sub-27`.

The ERPLAB averaged ERP derivatives were anonymized by removing or replacing potentially identifying metadata fields, including original file paths, original filenames, original ERP names, and command history fields.
